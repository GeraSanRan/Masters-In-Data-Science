About

I work with the kind of data organizations actually have: exports from management software, inconsistent labels, duplicate records, and missing fields. I like the work between the raw file and the answer, and I like explaining the result in plain language.

At a recreational sports club, I cleaned and standardized membership records and began analyzing why members renew, expire, or cancel. This portfolio collects that work along with projects from my master's program.

Projects

Ten projects, each with a short summary and a link to its folder in the GitHub repository. Club-related projects use synthetic data so no real member appears; each README says so.

  • Tennis Scout AI

    A Streamlit app that turns a tennis player's statistics into a six-section scouting report, written by a small language model (Qwen2.5-0.5B) that I fine-tuned. Training data: 407 player-surface profiles built from the public Match Charting Project.

    Fine-tuning taught the report format (format compliance rose from 9.5% to 100%) and the model never quoted a wrong number, but its archetype choices agree with my rule-based labels only 33% of the time. I report that openly.

    Python, Hugging Face Transformers, Streamlit, Google Colab (DSC 670)
    Code available Project folder README Colab launcher

  • Member retention toolkit

    A reusable notebook that cleans member and check-in data, protects privacy, compares four models, and produces a ranked list of members drifting away, with plain-language reasons. Built on synthetic data so it can be shared safely.

    The best model beats the baseline modestly (PR-AUC about 0.33 versus 0.22) and most flags are false alarms, so the write-up treats the list as a prompt for friendly outreach.

    Python, scikit-learn, XGBoost (DSC 680)
    Code available Project folder Notebook

  • Member retention prediction

    Which members are likely to be retained, and which membership groups are at risk? A pipeline from a real club problem, published on a fully synthetic dataset so no real member appears.

    The model beats the baseline only weakly, and a fairness check across age bands found large gaps. Both are reported in the notebook.

    Python, pandas, scikit-learn. Logistic regression, decision tree, random forest
    Code available Project folder Notebook

  • Membership data cleaning

    Cleaning member exports for a pickleball and tennis club: splitting one messy file into one file per membership, harmonizing group codes, removing duplicates, checking ages, and removing contact details, with a change log.

    Python
    Code available Project folder Cleaning script

  • NBA three-point revolution: before and after Stephen Curry

    Did the league's three-point percentage rise after Curry arrived in 2009? Not much: it moved from about 35.4% to 35.8%, while attempts per game nearly doubled (15 to 28). The write-up uses a t-test, a bootstrap interval, and segmented regression, and explains why a before/after comparison cannot show that Curry caused the change.

    Python, pandas, SciPy, statsmodels, public Basketball-Reference data
    Code available Project folder Notebook

  • Court demand forecasting

    Forecasting hourly court bookings a week ahead so a club can plan staffing. On synthetic data, a ridge model on weekday-and-hour slots cut the error to 1.82 courts, versus 2.66 for a plain average.

    Python, scikit-learn, time series
    Code available Project folder Notebook

  • Member segmentation

    Clustering 1,500 synthetic members by visits, classes, guest passes, and spend. The best fit was three groups: a core group, a low-engagement group that is the likely retention risk, and a social group.

    Python, scikit-learn, k-means, PCA
    Code available Project folder Notebook

  • Pickleball ladder ratings

    A simulation of a ladder day where winners move up a court and losers move down. With few rounds, an Elo rating sorts players by skill much better than court position; after about six rounds the two are about equal.

    Python, NumPy, simulation
    Code available Project folder Notebook

  • Club analytics with SQL

    Five SQL queries on a synthetic club database: revenue and churn by plan, busiest hours, engagement, and a list of active members who have not visited in 60 days.

    SQL, SQLite, Python
    Code available Project folder Queries

  • Club operations dashboard

    A one-page dashboard with four KPI tiles and four charts (visits, revenue by plan, churn by plan, visits by hour), built from the SQL project's database.

    Python, matplotlib, HTML
    Code available Project folder Dashboard code
